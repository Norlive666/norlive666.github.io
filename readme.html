个人博客网站项目

1. 网站简介

这是一个由 AI 辅助搭建的个人博客页面。我将在这里分享我个人的学习心得，以及我个人应用的下载包。

2. 目的

我希望通过该网站以一种更简单直接的方式向更多的人分享我开发的更好用的东西。希望以此为大家抹平信息差/提供一种更方便的工具。

3. 网站搭建

本网站借助 GitHub 的 Pages 功能免费部署。方法如下：

  • 新建仓库并命名。注：格式必须严格按照 <用户名>.github.io 的格式。例如：norlive666.github.io
  • 在仓库根目录新建一个 index.html 网页文件即可，GitHub 会自动启动 Pages 构建并发布上线。具体代码可参考本人仓库。
