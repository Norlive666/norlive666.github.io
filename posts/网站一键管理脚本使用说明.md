# 🚀 个人网站一键管理与发布脚本（update.sh）使用指南

本文档介绍针对个人主页及博客系统量身打造的 **全自动管理脚本（`update.sh` / `site_manager.py`）** 的核心功能，以及如何将其无缝配置到 `~/下载` 目录中随时随地调用。

---

## 一、脚本的核心作用

在以往更新网站时，通常需要经历繁琐的流程：
1. 手动把文章复制到仓库子目录；
2. 打开 `index.html` 手工写 HTML 代码添加卡片；
3. 计算文章篇数并手动修改；
4. 如果是超过 100MB 的安装包，还要打开网页后台新建 Release、上传再复制链接；
5. 最后手动输入一串 `git add`、`git commit`、`git push`。

**本脚本将上述所有操作浓缩为“一键全自动执行”：**

* 📝 **自动发布博客**：输入任意 `.md` 路径，脚本自动提取第一行大标题与前两行内容摘要，复制到 `posts/` 目录，并在主页自动生成卡片并更新文章总篇数。
* 📦 **自动上传大文件**：输入安装包路径（如 `.exe` / `.zip`），自动调用 GitHub Releases API 上传云端资产库（突破 100MB 单文件限制），并自动在主页生成下载卡片。
* 🔄 **安全极速同步**：自动复用系统的 GitHub 授权 Token，支持网络波动 3 次自动重试，免去输入账号密码的繁琐。
* 🖥️ **交互式友好菜单**：无需记忆命令，直接启动即有编号菜单指引。

## 二、如何配置该脚本到 `~/下载` 目录

为了让你在 `~/下载` 文件夹内操作文件时最省事，推荐以下两种配置方式：

### 方式 1：在 `~/下载` 建立一键软链接（最推荐）

在终端中执行以下命令，在 `~/下载` 目录下建立一个名为 `一键更新网站.sh` 的快捷方式：

```bash
ln -sf /home/norlive/private_work/norlive666.github.io/update.sh ~/下载/一键更新网站.sh
```

**效果：**
以后你打开 `~/下载` 文件夹，就会看到一个 `一键更新网站.sh` 的脚本。进入下载目录只需运行：
```bash
cd ~/下载
./一键更新网站.sh
```

---

### 方式 2：使用已为你配置好的全局终端命令 `blog`（随时随地）

系统已在你的 `~/.bashrc` 中写入了别名。无论你当前位于哪个文件夹（包括 `~/下载`），都可以直接使用 `blog` 命令！

* 如果在 `~/下载` 目录下写好了一个 `新文章.md`，直接输入：
  ```bash
  cd ~/下载
  blog post 新文章.md
  ```
  *(甚至不需要输入长长的绝对路径，直接填当前目录的文件名即可！)*

## 三、在 `~/下载` 目录下的日常使用范例

### 场景 1：在下载目录写好了一篇博文，一键发布
假设你在 `~/下载` 里用编辑器写好了一个 `DeepSeek使用技巧.md`：

```bash
cd ~/下载
blog post DeepSeek使用技巧.md "技巧心得"
```
> **全自动完成**：文章自动拷贝到网站 `posts/` 目录 $\rightarrow$ 主页自动出现新文章卡片 $\rightarrow$ 自动推送到 GitHub $\rightarrow$ 30 秒后全网可访问。

---

### 场景 2：在下载目录放置了一个新的安装包，一键发布下载
假设你在 `~/下载` 里制作了一个软件安装包 `my-tool-setup.exe`：

```bash
cd ~/下载
blog upload my-tool-setup.exe "这是新版本的工具整合包"
```
> **全自动完成**：自动走 GitHub Releases 上传文件（支持大文件） $\rightarrow$ 自动获取高速直链 $\rightarrow$ 主页【公共资源下载】区域自动增加卡片并展示文件大小。

---

### 场景 3：打开交互式菜单慢慢选
直接在终端敲：
```bash
blog
```
会显示菜单界面：
```text
==============================================
   🚀 T大帅的个人网站 · 一键管理助手
==============================================
 [1] 📝 发布新博客（支持输入 .md 路径，自动解析并挂载）
 [2] 📦 上传下载包（支持大文件，自动上传 Release 并挂载）
 [3] 🔄 一键同步与推送当前所有改动至 GitHub
 [4] 🌐 在浏览器打开我的网站
 [0] 🚪 退出
----------------------------------------------
```
输入对应数字后按回车，根据中文提示粘贴文件即可。

## 四、常见问题说明

1. **发布后网站多久生效？**
   * GitHub Actions 构建需要约 **20 ~ 40 秒**。推送成功后稍等片刻，在浏览器中按 `Ctrl + F5` 强制刷新即可看到新内容。
2. **需要配置 GitHub 账号密码吗？**
   * 不需要。脚本已直接对接系统里已登录的 `gh` 凭证。
3. **脚本存放在哪里？**
   * 脚本主文件存放在仓库根目录：`/home/norlive/private_work/norlive666.github.io/site_manager.py` 与 `update.sh`。
